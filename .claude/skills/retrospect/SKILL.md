# retrospect 스킬

이번 세션에서 배운 내용을 `LESSONS.md`에 누적한다. 실행할수록 지식 베이스가 쌓이는 시스템 루프다.

---

## 언제 사용하나

- 세션 마무리 시 항상 실행
- 예상치 못한 버그를 잡거나 새로운 패턴을 발견했을 때
- 다음 대화에서 같은 실수를 반복하고 싶지 않을 때

---

## 워크플로우

### 1단계: 이번 세션 파악

아래 명령을 병렬로 실행해 세션 맥락을 수집한다.

```bash
# 이번 세션 커밋 목록 (최근 20개)
git log --oneline -20

# 오늘 변경된 파일
git diff --stat HEAD~5..HEAD 2>/dev/null || git diff --stat

# LESSONS.md 마지막 엔트리 (이미 기록된 내용 파악용)
tail -50 LESSONS.md 2>/dev/null || echo "(LESSONS.md 없음)"
```

### 2단계: 회고 내용 작성

수집한 맥락 + 현재 대화 기록을 바탕으로 아래 항목을 도출한다.

**작업 내용** (bullet list)
- 이번 세션에서 구현하거나 수정한 것

**이슈 & 해결** (표)

| 이슈 | 원인 | 해결 |
|------|------|------|
| 실제로 막혔던 문제 | 왜 발생했는지 | 어떻게 해결했는지 |

*이슈가 없었으면 이 섹션은 생략한다.*

**다음 세션 체크리스트**
- 다음에 이 프로젝트를 열면 먼저 확인해야 할 것들
- 미완료 작업, 알려진 제한사항, 주의사항

**기억할 패턴**
- 이번에 새로 알게 된 코드 패턴, 라이브러리 quirk, 설정 gotcha
- *이미 LESSONS.md에 있는 내용은 중복 기록하지 않는다*

### 3단계: LESSONS.md에 추가

LESSONS.md가 없으면 헤더를 포함해 새로 만든다.

파일 구조:
```
# LESSONS.md

이 프로젝트에서 세션별로 배운 내용 누적. `/retrospect` 스킬이 유지 관리한다.

---

## YYYY-MM-DD

### 작업 내용
...

### 이슈 & 해결
...

### 다음 세션 체크리스트
...

### 기억할 패턴
...

---
```

새 엔트리는 **파일 상단 `---` 바로 아래에 추가** (최신이 위에 오도록).

### 4단계: 메모리 업데이트 판단

아래 조건 중 하나라도 해당하면 `/Users/kangminseong/.claude/projects/-Users-kangminseong-repository-mybrary/memory/` 안의 관련 파일을 업데이트한다.

- 새로운 피드백/선호가 드러난 경우 → `feedback_*.md`
- 프로젝트 상태나 의사결정이 바뀐 경우 → `project_*.md`
- 사용자에 대한 새로운 정보를 얻은 경우 → `user_*.md`

**MEMORY.md 인덱스도 함께 갱신한다.**

메모리 파일 프론트매터 형식:
```markdown
---
name: <kebab-case-slug>
description: <한 줄 설명>
metadata:
  type: <user | feedback | project | reference>
---

내용 본문
```

### 5단계: 완료 보고

아래 형식으로 사용자에게 보고한다.

```
/retrospect 완료

LESSONS.md에 추가된 항목:
- 작업: N개
- 이슈 & 해결: N개
- 다음 세션 체크리스트: N개
- 기억할 패턴: N개

메모리 업데이트: <업데이트한 파일 목록 또는 "없음">
```

## 규칙

1. **중복 금지** — 이미 LESSONS.md에 있는 내용은 다시 쓰지 않는다
2. **구체적으로** — "버그 수정"이 아니라 "Thymeleaf 3.1에서 `#request`가 null로 반환되는 문제 → `@ModelAttribute`로 우회"처럼 재현 가능한 수준으로 기록
3. **짧게** — 이슈당 2~3줄. 장문 설명은 코드 주석이나 커밋 메시지에 있다
4. **날짜 헤더** — 반드시 `## YYYY-MM-DD` 형식 (오늘 날짜)
5. **이미 오늘 엔트리가 있으면** — 새 `##` 헤더를 만들지 말고 기존 섹션에 추가한다
